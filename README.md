An adult-oriented, browser-based world-building console for drafting fictional protagonists, locations, relationship arcs, ventures and story events on an interactive map.

**Public prototype:** <https://auraofintelligence.github.io/eros-pc/>

## What it does

- creates and revisits story nodes
- keeps a protagonist codex, narrative-arc library and venture list
- places fictional nodes on a Leaflet map
- builds self-contained prompt packages for later use with an LLM
- exports story logs as TXT, JSON or CSV
- backs up and restores the full browser state as JSON

## Use it

Open `index.html` in a browser. There is no build step. Map tiles and the Leaflet library are loaded from external services, but the prototype makes no LLM calls.

Entries are stored in the current browser's `localStorage`. Download a JSON backup before clearing browser data or moving devices.

## Status and boundaries

This is an early creative-writing prototype, not a relationship, consent, cultural, safety or travel authority. Its labels and prompts do not establish real-world consent or permission. Keep real people's identities, intimate records and private notes out of the public repository and review exports before sharing them.
